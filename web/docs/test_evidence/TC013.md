   - PJ名: あ（1文字・最小）
   - PJ種別: 運用（最短の選択肢）

**現象**: 
- 登録確認画面において、PJ種別とPJ分類の値が入力値と異なって表示されている

**入力値**: 
- PJ種別: 「運用」
- PJ分類: 「Ａ」

**確認画面での表示**: 
- PJ種別: 「Ｃ」
- PJ分類: 「ＥＲＰ導入支援」

**影響度**: 中
**優先度**: 高

この不具合により、ユーザーが確認画面で入力内容を正しく確認できない可能性があります。
