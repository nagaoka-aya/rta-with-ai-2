1. **PJ名の文字種チェック**: プロジェクト名に半角文字が含まれているとエラーになる。設計書通りの動作。
2. **日付フィールドの形式**: 日付入力フィールドはHTML5のtype="date"属性を使用しており、yyyy-MM-dd形式での入力が必要。
3. **売上高の表示**: 確認画面では3桁ごとにカンマ区切りで表示される（設計書通り）。
4. **備考の改行**: 備考欄の改行は確認画面で正しく再現される（設計書通り）。
5. **顧客検索機能**: 顧客検索画面で選択した顧客が、元の画面に正しく反映される。
