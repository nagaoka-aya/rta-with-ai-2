# プロジェクト登録機能実装計画

## 1. 概要

プロジェクト登録機能は、ユーザーがプロジェクト情報を入力・確認・登録する3画面構成のWebアプリケーションです。Spring Boot + Spring MVCを使用し、レイヤードアーキテクチャに従って実装します。

## 2. クラス図

    ProjectCreateService ->> ProjectCreateMapper: (3) selectOrganizationsByUpperId(null)

    ProjectViewHelper ->> CustomerClient: (9) getCustomerDetail(clientId)

### 登録イベント
```mermaid
sequenceDiagram
    participant Browser
    participant ProjectCreateController
    participant ProjectCreateService
    participant ProjectCreateMapper
    participant Project

    %% ① 登録リクエスト
    Browser ->> ProjectCreateController: (1) POST /project/register (ProjectCreateForm)
    
    %% ② バリデーション
    ProjectCreateController ->> ProjectCreateController: (2) validate form
    
    %% ③ プロジェクト登録
    ProjectCreateController ->> ProjectCreateService: (3) createProject(ProjectCreateDto)
    ProjectCreateService ->> ProjectCreateMapper: (4) insert(Project)
    ProjectCreateMapper ->> Project: (5) insert into project table
    Project -->> ProjectCreateMapper: (6) success
    ProjectCreateMapper -->> ProjectCreateService: (7) success
    ProjectCreateService -->> ProjectCreateController: (8) success
    
    %% ④ 完了画面へリダイレクト
    ProjectCreateController -->> Browser: (9) redirect:/project/complete
```

### 戻るイベント
```mermaid
sequenceDiagram
    participant Browser
    participant ProjectCreateController
    participant ProjectCreateService
    participant ProjectCreateMapper
    participant Organization

    %% ① 戻るリクエスト
    Browser ->> ProjectCreateController: (1) POST /project/back (ProjectCreateForm)
    
    %% ② 事業部が選択されている場合、部門一覧を取得
    alt 事業部が選択されている場合
        ProjectCreateController ->> ProjectCreateService: (2) searchOrganizations(form.divisionId)
        ProjectCreateService ->> ProjectCreateMapper: (3) selectOrganizationsByUpperId(form.divisionId)

        Organization -->> ProjectCreateMapper: (5) department list
        ProjectCreateMapper -->> ProjectCreateService: (6) department list
        ProjectCreateService -->> ProjectCreateController: (7) List<OrganizationDto>
        ProjectCreateController ->> ProjectCreateController: (8) model.addAttribute("departments", departments)
    end
    
    %% ③ 登録画面表示（フォームデータと部門一覧をモデルに設定）
    ProjectCreateController -->> Browser: (9) project/create.html (with form data and departments)
```

## WA10201 プロジェクト登録機能 GOAL分割タスクリスト

## GOAL 1: 基本画面表示とルーティング設定 - 詳細実装計画

- **完了条件**: 
  - プロジェクト登録画面（WA1020101）が正常に表示される
  - 確認画面（WA1020102）、完了画面（WA1020103）の画面遷移が動作する
  - 各画面の基本レイアウトとフォーム項目が表示される
  - 戻るボタン、確認ボタン、登録ボタンが配置され、画面遷移のみ実行される

### GOAL 2: 初期表示データ取得機能
- **完了条件**:
  - @ModelAttributeによって事業部プルダウンに組織マスタから取得した事業部一覧が表示される

  - PJ分類ラジオボタンにコードマスタから取得した値が表示される

# GOAL 3: 動的部門取得機能（Ajax）の詳細実装計画
