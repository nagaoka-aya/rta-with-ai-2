# プロジェクト登録機能実装計画

## 1. 概要

プロジェクト登録機能は、ユーザーがプロジェクト情報を入力・確認・登録する3画面構成のWebアプリケーションです。Spring Boot + Spring MVCを使用し、レイヤードアーキテクチャに従って実装します。

## WA10201 プロジェクト登録機能 GOAL分割タスクリスト


### GOAL 1: 基本画面表示とルーティング設定
- **完了条件**: 
  - プロジェクト登録画面（/project/create）が正常に表示される
  - 確認画面（/project/create/confirm）、完了画面（/project/create/complete）の画面遷移が動作する
  - 各画面の基本レイアウトとフォーム項目が表示される
  - 戻るボタン、確認ボタン、登録ボタンが配置され、画面遷移のみ実行される（バリデーションやデータ処理は後のGOALで実装）

#### ステップ 1: ProjectCreateFormクラスの作成
- **編集対象ファイル:** `web/src/main/java/com/example/web/project/form/ProjectCreateForm.java`（新規作成）
- **目的:** 画面項目を保持するためのシンプルなFormクラスを作成する
- **内容:** 
  - プロジェクト登録に必要な全ての項目をプロパティとして定義する
  - 各プロパティにgetterとsetterを実装する
  - この段階ではバリデーションアノテーションは付与しない
  - プロパティ: divisionId(String), organizationId(String), projectName(String), projectType(String), projectClass(String), sales(BigDecimal), clientId(String), projectManager(String), projectLeader(String), projectStartDate(LocalDate), projectEndDate(LocalDate), note(String)
- **ポイント:** 
  - バリデーション機能はまだ実装しない
  - 日付項目はLocalDate型で定義する
  - 金額項目はBigDecimal型で定義する

#### ステップ 2: ProjectCreateControllerクラスの作成
- **編集対象ファイル:** `web/src/main/java/com/example/web/project/controller/ProjectCreateController.java`（新規作成）
- **目的:** プロジェクト登録機能のコントローラーを作成し、基本的な画面遷移を実装する
- **内容:**
  - @Controllerアノテーションを付与する
  - @RequestMapping("project/create")でベースパスを指定する
  - @TransactionTokenCheck("project/create")アノテーションを付与する
  - index()メソッド: @GetMappingで登録画面を表示し、新しいProjectCreateFormをモデルに追加する
  - confirm()メソッド: @PostMapping("confirm")と@TransactionTokenCheck(type = TransactionTokenType.BEGIN)で確認画面に遷移する
  - execute()メソッド: @PostMapping(path = "execute", params = "submit")で完了画面にリダイレクトする
  - back()メソッド: @PostMapping(path = "execute", params = "back")で入力画面に戻る
  - complete()メソッド: @GetMapping("complete")で完了画面を表示する
- **ポイント:** 
  - この段階では画面遷移のみ実装し、業務ロジックは含めない
  - ProjectCreateFormインスタンスをモデルに追加するが、フォームバインディングは使用しない
  - 画面間でのデータ受け渡しは実装しない

#### ステップ 3: 登録画面HTMLテンプレートの作成
- **編集対象ファイル:** index.html（新規作成）
- **目的:** プロジェクト登録入力画面のHTMLテンプレートを作成する
- **内容:**
  - common/layoutを使用したレイアウトを作成する
  - formタグにaction="/project/create/confirm"とmethod="post"を設定する
  - 各項目の入力フィールドを配置する（事業部select、部門select、PJ名input、PJ種別select、PJ分類radio、売上高input、顧客label+button、PMInput、PLInput、開始日input、終了日input、備考textarea）
  - 確認ボタン（type="submit"）を配置する
  - 静的な選択肢でプルダウンとラジオボタンを実装する
- **ポイント:** 
  - この段階ではth:fieldやth:objectは使用しない
  - 静的な選択肢（例：新規開発、保守、改良など）でプルダウンを実装する
  - エラー表示領域は用意するが、まだ表示機能は実装しない

#### ステップ 4: 確認画面HTMLテンプレートの作成
- **編集対象ファイル:** confirm.html（新規作成）
- **目的:** 入力内容を確認するための画面を作成する
- **内容:**
  - common/layoutを使用したレイアウトを作成する
  - 各項目をラベル形式で表示する領域を作成する
  - formタグのactionを"/project/create/execute"に設定する
  - 戻るボタン（name="back"、type="submit"）と登録ボタン（name="submit"、type="submit"）を配置する
  - 現時点では静的なダミーデータで表示する
- **ポイント:** 
  - この段階では入力値の表示はせず、固定の確認用文言を表示する
  - hiddenフィールドは配置するが、値の設定は後のGOALで実装する

#### ステップ 5: 完了画面HTMLテンプレートの作成
- **編集対象ファイル:** complete.html（新規作成）
- **目的:** 登録完了を通知する画面を作成する
- **内容:**
  - common/layoutを使用したレイアウトを作成する
  - 「プロジェクトの登録が完了しました」というメッセージを表示する
  - 「新しいプロジェクトを登録する」リンクボタンを配置し、/project/createにリンクする
- **ポイント:** シンプルな完了メッセージのみで十分

#### ステップ 6: 基本画面遷移の動作確認
- **編集対象ファイル:** 上記で作成した全ファイル
- **目的:** 各画面が正常に表示され、基本的な画面遷移が動作することを確認する
- **内容:**
  - アプリケーションを起動し、各画面にアクセスできることを確認する
  - ボタンクリックによる画面遷移が正常に動作することを確認する
  - コンパイルエラーや実行時エラーが発生しないことを確認する
- **ポイント:** 
  - データの受け渡しやバリデーションは動作しなくても問題ない
  - 画面が表示され、遷移することが重要
