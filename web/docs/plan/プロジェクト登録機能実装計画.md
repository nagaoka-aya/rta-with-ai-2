# プロジェクト登録機能実装計画

## 1. 概要

プロジェクト登録機能は、ユーザーがプロジェクト情報を入力・確認・登録する3画面構成のWebアプリケーションです。Spring Boot + Spring MVCを使用し、レイヤードアーキテクチャに従って実装します。

## WA10201 プロジェクト登録機能 GOAL分割タスクリスト

## GOAL 1: 基本画面表示とルーティング設定 - 詳細実装計画

- **完了条件**: 
  - プロジェクト登録画面（WA1020101）が正常に表示される
  - 確認画面（WA1020102）、完了画面（WA1020103）の画面遷移が動作する
  - 各画面の基本レイアウトとフォーム項目が表示される
  - 戻るボタン、確認ボタン、登録ボタンが配置され、画面遷移のみ実行される（バリデーションやデータ処理は後のGOALで実装）

#### ステップ 1: ProjectCreateControllerクラスの作成
- **編集対象ファイル:** `web/src/main/java/com/example/web/project/controller/ProjectCreateController.java`（新規作成）
- **目的:** シーケンス図の初期表示、確認、戻る、完了表示イベントのコントローラー部分を実装
- **内容:** 
  - `@Controller`アノテーションと`@RequestMapping("project/create")`を付与
  - `@TransactionTokenCheck("project/create")`アノテーションを付与して二重送信防止を設定
  - `index()`メソッド：GET /project/create で登録画面を表示
  - `confirm()`メソッド：POST /project/create/confirm で確認画面を表示（バリデーションは空実装）
  - `execute()`メソッド：POST /project/create/execute で登録処理（空実装）
  - `back()`メソッド：POST /project/create/execute?back で戻り処理
  - `complete()`メソッド：GET /project/create/complete で完了画面を表示
- **ポイント:** 
  - 各メソッドは画面遷移のみ実装し、業務ロジックは含めない
  - フォームバインディング用のProjectCreateFormクラスを引数に含める
  - `@TransactionTokenCheck(type = TransactionTokenType.BEGIN)`を確認画面で使用

#### ステップ 2: ProjectCreateFormクラスの作成
- **編集対象ファイル:** `web/src/main/java/com/example/web/project/form/ProjectCreateForm.java`（新規作成）
- **目的:** 画面とコントローラー間のデータ転送を担当するFormクラスを作成
- **内容:**
  - 仕様書の画面項目定義に基づいて全てのプロパティを定義
  - `divisionId`、`organizationId`、`projectName`、`projectType`、`projectClass`、`sales`、`clientId`、`projectManager`、`projectLeader`、`projectStartDate`、`projectEndDate`、`note`プロパティを作成
  - 各プロパティに適切なgetter/setterを実装
  - 日付項目は`@DateTimeFormat(pattern = "uuuu-MM-dd")`アノテーションを付与
  - バリデーションアノテーションは後のGOALで追加するため、この段階では定義しない
- **ポイント:** 
  - JavaBeansパターンに準拠
  - プロパティ名は仕様書の物理名と一致させる

#### ステップ 3: HTMLテンプレートのThymeleaf連携対応
- **編集対象ファイル:** index.html
- **編集対象のメソッド:** フォーム要素全体
- **目的:** 既存のHTMLテンプレートをThymeleafのフォームバインディングに対応させる
- **内容:**
  - `<form>`タグに`th:action="@{/project/create/confirm}"`と`th:object="${projectCreateForm}"`を追加
  - 各input要素に`th:field="*{プロパティ名}"`を追加（例：`th:field="*{projectName}"`）
  - select要素（事業部、部門、PJ種別）に`th:field="*{プロパティ名}"`を追加
  - radio要素（PJ分類）に`th:field="*{projectClass}"`を追加
  - 確認ボタンに`name="confirm"`属性を追加
- **ポイント:** 
  - 既存のHTML構造は維持しつつ、Thymeleaf属性のみ追加する
  - この段階ではプルダウンの選択肢は静的な値のままでよい

#### ステップ 4: 確認画面HTMLテンプレートの編集
- **編集対象ファイル:** confirm.html
- **編集対象のメソッド:** フォーム要素全体
- **目的:** 確認画面で入力値を表示し、戻るボタンと登録ボタンの画面遷移を実装
- **内容:**
  - `<form>`タグに`th:action="@{/project/create/execute}"`と`th:object="${projectCreateForm}"`を追加
  - 表示用の各項目に`th:text="*{プロパティ名}"`を追加
  - 全ての入力値をhiddenフィールドとして保持（`th:field="*{プロパティ名}"`）
  - 戻るボタンに`name="back"`属性を追加
  - 登録ボタンに`name="submit"`属性を追加
- **ポイント:** 
  - この段階では名称変換（組織ID→組織名等）は実装しない
  - 値がそのまま表示される状態でよい

#### ステップ 5: 完了画面HTMLテンプレートの編集
- **編集対象ファイル:** complete.html
- **編集対象のメソッド:** リンク要素
- **目的:** 完了画面から次の登録への導線を提供
- **内容:**
  - 「次へ」ボタンに`th:href="@{/project/create}"`を追加
- **ポイント:** 
  - 完了画面は表示のみで、特別な処理は不要

#### ステップ 6: コントローラーのフォームオブジェクト初期化実装
- **編集対象ファイル:** `web/src/main/java/com/example/web/project/controller/ProjectCreateController.java`
- **編集対象のメソッド:** 各メソッドのシグネチャ調整
- **目的:** フォームオブジェクトの適切な初期化と画面間での値の受け渡しを実装
- **内容:**
  - `index()`メソッドに`ProjectCreateForm form`引数を追加
  - `confirm()`メソッドで受け取ったフォームをそのままModelに設定
  - `back()`メソッドで確認画面のフォーム値を登録画面に渡す
  - 各メソッドで適切な戻り値（テンプレートパス）を設定
- **ポイント:** 
  - フォームオブジェクトが画面間で正しく引き継がれることを確認
  - この段階ではバリデーションは実装しない

#### 動作確認
- **操作 1:** ブラウザで`http://localhost:8080/project/create`にアクセス
- **期待する結果 1:** プロジェクト登録画面が表示され、フォーム項目（事業部、部門、PJ名、PJ種別、PJ分類、売上高、顧客、PM、PL、開始日、終了日、備考）と確認ボタンが表示される

- **操作 2:** フォームに適当な値を入力して確認ボタンをクリック
- **期待する結果 2:** プロジェクト登録確認画面に遷移し、入力した値が表示される（ID値がそのまま表示されても可）

- **操作 3:** 確認画面で戻るボタンをクリック
- **期待する結果 3:** 登録画面に戻り、入力した値が保持されている

- **操作 4:** 確認画面で登録ボタンをクリック  
- **期待する結果 4:** 完了画面に遷移し、「登録が完了しました」メッセージが表示される

- **操作 5:** 完了画面で「次へ」ボタンをクリック
- **期待する結果 5:** 登録画面に戻り、フォームが空の状態で表示される
